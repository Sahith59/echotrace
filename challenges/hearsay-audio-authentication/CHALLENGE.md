# NSA — Hearsay Audio Authentication

🔉 **Challenge 1: HEARSAY: The Audio Authentication Challenge**

Scenario:

Welcome to your first assignment with the National Security Agency’s Multimedia Forensics and Authentication Team.  The stakes have never been higher. Your adversaries are already deploying synthetic-voice systems at scale. The question isn’t whether the fake call will come, it is whether we’ll know it’s fake when it does.

Your mission:

Build an AI system that can autonomously analyze an audio file, determine the likelihood score it has been synthesized, and the type of manipulation. The system should take any audio file as input (WAV, MP3, M4A, etc...), automatically orchestrate multiple forensic analysis techniques, output a synthetic likelihood score (0-100%), and optionally identify the type of manipulation. A labeled training set and held out test set will be provided. Submit a CSV file with the predicted results on the test set for evaluation. Cloud services, open-source LLMs, speech models, and signal-processing toolkits are all fair game. How you combine them is up to you!
