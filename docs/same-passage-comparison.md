# Same-passage listening demonstration

The Investigation home screen compares two **different recordings of the same Jane Eyre excerpt**. One is a human reading in `original/en/`; one was generated by Chatterbox in `fake/en/Chatterbox/`. They are not claimed to be the same speaker or a cloned identity.

Both files come from the pinned [`mueller91/MLAAD-tiny` revision](https://huggingface.co/datasets/mueller91/MLAAD-tiny/tree/9143e5ea709575ebab6bec52840a1043aada7bb1). The generated file is part of the fixed 24-file diagnostic sample. The human counterpart is a separate, one-file listening reference and does not alter that sample's manifest, counts or training exclusion claims. The backend verifies the exact byte count and SHA-256 before serving either file. The setup command requires explicit source/license review and downloads only the pinned URLs.

| Audio | Duration | Bytes | SHA-256 |
| --- | ---: | ---: | --- |
| Human `original/en/jane_eyre_21_f000371.wav` | 8.412 s | 269,258 | `acbd08fac7031654ff5a746568a165fed77dc41d5b4c535518f11c90c6a5d3bf` |
| Generated `fake/en/Chatterbox/jane_eyre_21_f000371.wav` | 8.720 s | 279,118 | `15866bad9d5becc8e3bcf9d7203b74386d078086d80ce0241b2a5eb61b3e63db` |

Local faster-whisper `base` transcribed the first sentence identically for both: “And you are indebted to no one for helping you to get rid of one vacant moment.” The second sentence also matched apart from a comma before “forbearance.” This transcription check supports a **same-passage** label; it is not a formal alignment or speaker-equivalence test. Listen to both before describing them to judges.

The live browser's **Analyze both recordings** control submitted both audio files through the ordinary upload path. The app saved two NII cases, both completed, with raw uncalibrated synthetic-high scores:

| Recording | Raw model score | Display |
| --- | ---: | ---: |
| Human | `0.00001920938848343212` | 0 / 100 |
| Generated | `0.9999682903289795` | 100 / 100 |

This contrast makes the workflow easy to demonstrate but **does not measure detector accuracy**. The [NII model card](https://huggingface.co/nii-yamagishilab/wav2vec-small-anti-deepfake) lists MLAAD among its training sources. The selected clips are therefore not an independent test of NII. The [separate ArA-DF-2026 stress check](ara-df-2026-stress-check.md) is stronger evidence of a failure mode: at a fixed 0.5 threshold on 198 eligible selected clips, it missed 38 of 98 synthetic recordings and falsely flagged 7 of 100 genuine recordings. That selected Arabic/channel set is still not representative of NSA sponsor data.

To repeat locally, from `challenges/hearsay-audio-authentication/backend` first review the printed data/license sources, then run `uv run python -m echotrace.setup_examples --confirm-source-review --include-paired-reference`. Start the app, open **Investigation**, play each clip, then choose **Analyze both recordings**. The two saved scores and **Open analysis** buttons should appear. If either file is absent or altered, the panel disables analysis and names the setup command rather than substituting other audio.
